alphabet

Core Meaning Overview

Alphabet names an ordered letter system and, by extension, a field-specific symbol set.

字母表；符号系统

Semantic Map

NOUN

  • alphabet.N1
  • alphabet.N2

Lexical Element Subcards

alphabet.N1 · NOUN · ordered set of letters

The complete set of letters used to write a language, conventionally arranged in a fixed order.

按固定顺序排列、用于书写语言的整套字母
