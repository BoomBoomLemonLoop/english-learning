already

Core Meaning Overview

Already places a state or event before a reference time, often earlier than expected.

已经；早于参照时间

Semantic Map

ADVERB

  • already.ADV1

Lexical Element Subcards

already.ADV1 · ADVERB · before now or a reference time

Before the time being discussed; often with the implication that the event happened sooner than expected or that the state now holds.

在当前或另一参照时间之前已经发生或成立
