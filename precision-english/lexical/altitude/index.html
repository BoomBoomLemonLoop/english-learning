altitude

Core Meaning Overview

Altitude organizes measured vertical position, especially height above sea level, and a specialized astronomical angular measure.

海拔；高度

Semantic Map

altitude.N1 · NOUN · height above a reference level

The vertical distance of a place or object above sea level or another stated reference level.

相对于基准面的垂直高度，通常指海拔

Near-Synonym Contrast

  • altitude vs height
