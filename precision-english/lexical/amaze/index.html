amaze

Core Meaning Overview

Amaze profiles a cause that produces very strong surprise in an experiencer.

使大为惊讶

Semantic Map

VERB

  • amaze.V1

Lexical Element Subcards

amaze.V1 · VERB · cause great surprise

To surprise someone very much.

使某人感到非常惊讶
