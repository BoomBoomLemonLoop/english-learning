易混词辨析 · Quick reference

comprise / consist of / constitute 整体 → 部分：comprise / consist of；部分 → 整体：constitute。
The system comprises A and B. / The system consists of A and B. / A and B constitute the system.

precise / precision / accurate / accuracy 计量学：precision 是重复测量的一致性；accuracy 是与真实值的接近程度。日常 precise 还可表示表达明确。
The results are precise but not necessarily accurate.

consistent / constant consistent 强调相符或表现稳定；constant 强调数值不变或持续不断。
The results are consistent with previous findings. / The shaft speed remains constant.

precede / preceding / precedent 先于（动词）/ 前面的（形容词）/ 先例（名词）。
The test precedes the analysis. / The preceding section. / Set a precedent.

miserable / misery 形容词表示痛苦；名词表示痛苦或悲惨境遇。
She felt miserable. / The delay added to her misery.

military / militant 军事、军队 / 激进、强硬；二者并不等同。
Military personnel. / A militant stance.

conceive / conception / concept 构想（动词）/ 观念、构想过程（名词）/ 概念（名词）。
Conceive a design. / A narrow conception of efficiency. / A fundamental concept.

indifferent / indignant 漠不关心 / 因不公而愤慨。
They were indifferent to the complaints. / She was indignant at the unfair decision.
