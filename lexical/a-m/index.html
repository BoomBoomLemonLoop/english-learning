a.m.

Core Meaning Overview

A.m. identifies clock times from midnight to before noon.

上午；午夜至正午

Semantic Map

TIME MARKER

  • a.m..ADV1

Lexical Element Subcards

a.m..ADV1 · TIME MARKER · between midnight and noon

Used after a clock time to identify the period from midnight up to noon.

午夜以后、正午以前的时刻标记
