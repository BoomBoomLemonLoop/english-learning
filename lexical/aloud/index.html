aloud

Core Meaning Overview

Aloud means in an audible voice rather than silently.

出声地；大声说出

Semantic Map

ADVERB

  • aloud.ADV1

Lexical Element Subcards

aloud.ADV1 · ADVERB · audibly, not silently

In a voice that can be heard, especially when reading, thinking, or speaking words.

出声地，而不是默读或默想

Grammar Patterns

  • read/say/think + aloud
    表达“出声地，而不是默读或默想”的结构：read/say/think + aloud
    该结构标明这个意义所要求的补语形式、词序或作用范围；使用时不能只按中文意思自由替换介词或不定式形式。

Collocations

Examples

    请把说明朗读出来。

    她把疑问说出了口：这个计划是否会奏效。
